# 归宅

无依赖的网页恐怖小游戏。当前正式流程：开始画面 → 两幕背景说明 → 第一晚回到老宅 → 开灯、上二楼 → 点击最右自己的房门休息。第一晚平安无事，其他房间和次日剧情暂未制作。

第一晚手机无短信、无未接来电，也没有消息红点；菜园暂不开放，门口画面除大门外没有场景点击反馈。进入客厅后，除灯、楼梯以及必要的转身导航外，点击电视、房门、手电筒或工具栏均提示“今天赶路累了，夜深了，先休息。”到二楼后点击自己的房门显示本段完成，不触发停电，也不自动进入第二天。

## 本地运行

在仓库根目录执行 `python3 -m http.server 8000 --directory game`，用浏览器访问本地服务。也可直接打开 game/index.html，无需构建或安装依赖。

## Netlify 发布

1. 登录 Netlify，选择 Add new project → Import an existing project → GitHub。
2. 授权访问并选择 kunkun2222/codex，部署分支选择 main。
3. Base directory 留空，Build command 留空，Publish directory 填 game。根目录 netlify.toml 已声明发布目录。
4. 点击 Deploy，完成后打开 Netlify 提供的网站地址。

也可将 game 文件夹拖到 Netlify Drop 发布。之后向 main 推送更改，可触发已连接站点的自动部署。

game.js 保留了之前的完整剧情草稿，当前网页只加载 demo.js。

## 图片画廊

打开 `game/gallery.html` 可查看九张场景作品，支持放大与下载。GitHub 中也可打开根目录 `GALLERY.md`。大门口分别采用 `entrance-v3-on.png` 与 `entrance-v3-off.png`：灯光状态直接决定显示哪张，视角切换没有从亮到暗的滤镜动画。两张图均已去掉门左侧墙面开关。

## 菜园线索预览

菜园是独立场景 `assets/garden-v1.png`，不是外景放大。画廊中的“单独预览线索互动”或 `index.html?preview=garden` 可进入美术测试：点击左侧断梗、右侧脚印分别获得线索，备忘录会记录。这个入口仅用于检查美术与交互，正常第一晚不会解锁菜园，也没有新增次日剧情。

## 客厅开关与电视

最左侧墙面开关控制客厅灯，楼梯口开关独立控制楼梯灯。状态在切换视角时保留，刷新页面重置。电视四模式逻辑暂时保留供后续剧情使用，但第一晚点击只提醒休息，不开机。节目为静态示意画面，无音视频。

`demo.js` 的 `firstNight` 和 `gardenUnlocked` 管理当前流程；`restReminder` 统一疲劳提示；`restForNight` 是第一晚上楼休息节点。尚未制作其他房间。

## 二楼楼梯间

`upstairs-v2-on.png` / `upstairs-v2-off.png` 为同机位亮灯、灭灯图。左侧小门为杂物间，旁边陡木梯通无灯阁楼，中间为父母卧房，右侧为女主卧房，所有房门关闭。右墙开关与一楼楼梯灯共用 `stairLight` 状态，中间墙开关控制独立 `hallLight`。右下角返回一楼；各状态跨楼层保留。

第一晚只有自己的房门推进休息节点；其余门、阁楼木梯及空白区域都提示先休息，开关与返回按钮仍正常操作。卧房内部尚未制作。

二楼第二版进一步缩小杂物间门，并加入菜篓、旧桶、竹筐纸箱、木凳、草帽、布袋和朴素墙饰，亮灯与灭灯图同步。
