# 暮光小镇 · 为你留一盏灯

一个适合手机体验的原创趣味测试：通过 10 个故事场景，找到今晚为你留灯的小屋。包含 6 种结果、返回修改、重新测试和 PNG 分享卡下载。答案仅保留在页面内存中，不上传、不收集个人信息。

## 本地运行

需要 Node.js 22 或更新版本。

```bash
npm ci --cache /workspace/.npm-cache
npm run dev
```

开发服务默认使用 5173 端口。云环境中的对外访问方式取决于平台，不代表已经部署到公网。

## 构建

```bash
npm run build
npm run preview
```

构建产物在 `dist/`，可以部署到支持静态网站的托管平台。本项目不需要后端、数据库或 API 密钥。尚未接入小红书小游戏平台。

## 主要文件

- `src/main.js`：题目、结果、多个倾向累积的趣味计分、页面交互与分享卡绘制。
- `src/style.css`：响应式界面、田园配色与减少动态效果支持。
- `public/`：随项目提供的插画素材。

本测试是娱乐性的自我探索，不是经过心理学验证的量表，不用于诊断。
