# 暮光小镇 · 为你留一盏灯

原创的分支故事与人格倾向探索。24 个题目节点，每次经历 12 个共同场景和 3 个由选择触发的支线，共 15 题；得到 12 种主小屋之一，以及基于当次选择的个人侧写、恢复方式和选择回声。

这是娱乐性的自我探索，不是经过验证的心理量表，不用于诊断。分析中的拉扯是供自我观察的可能性，不是对真实人格的测量结论。答案仅保留在当前页面内存，不上传，不收集个人信息。

## 开发与构建

需要 Node.js 22 或更新版本。

```bash
npm ci --cache /workspace/.npm-cache
npm run dev
npm test
npm run build
```

开发端口默认 5173。生产文件在 `dist/`，可部署到静态网站托管平台。Netlify 连接分支 `website/twilight-village`，构建命令为 `npm run build`，发布目录为 `dist`。不需要后端、数据库或 API 密钥，尚未接入小红书小游戏平台。

## 内容维护

- `src/adventure.js`：24 道题、分支图、12 个结果主题、偏好计分和分析生成。选择会在送信、客房与面包店告别三处触发后续，之后回到共同故事；共有 64 种路线组合。
- `src/main.js`：页面、自动跳题、返回修改、结果展示与 PNG 卡片下载。回头改变分支选择会清除旧分支答案；只分析当前有效路线。
- `src/style.css`：深色背景、浅色选项、响应式插画与手写字体。
- `public/scenes/`：沿用的 10 张旅途插画，不同故事节点可能使用同一场景。
- `public/homes/`：沿用的 6 张小屋插画；新增的 6 种结果目前复用这些插画，本轮没有生成新图。
- `public/gallery.html`：可以不答题浏览现有 16 张插画的画廊。

计分使用探索、自主、联结、照料、反思、秩序六个原创叙事维度。各维度按当前路线可获得的分数归一化，使用两个主题倾向匹配主小屋，不展示伪精确的人格百分比。相近结果会提示倾向接近；具体“拉扯”需要对应倾向至少在三个不同故事情境中出现，否则使用谨慎的探索性说明。个人补充、今晚的恢复建议和两处真实选项回声来自本次答案。

## 字体

`public/fonts/twilight-wenkai.woff2` 是按当前文案裁剪的霞鹜文楷，许可证在同目录 `OFL.txt`。更改文案后，可在装有 `fonttools[woff]` 的 Python 环境中执行 `python3 scripts/subset-font.py`。原字体来自开发依赖 `@fontsource/lxgw-wenkai`。字体产物已提交，正常部署只需要 Node.js。

## 验证

`npm test` 检查所有 64 种路线、无效/不完整答案、废弃分支清除、真实选项引用、12 种结果可达性、同结果不同侧写和确定性。以上是程序逻辑测试，不等同于心理测量学验证。

使用 Chromium 在 320×568、375×667、390×690、390×844 与桌面 1440×1000 运行覆盖全部 24 个节点的四组路线；检查选项一屏可见、图片加载、结果与选择回声、返回改选、重测及 PNG 下载。结果页内容较长，允许正常滚动。文字放大或极小横屏也允许滚动，保留可读性。真实手机上的浏览器与保存图片体验仍需实际确认。
