# 暮光小镇 · 为你留一盏灯

一个适合手机体验的原创趣味测试：通过 10 个故事场景，找到今晚为你留灯的小屋。包含 6 种结果、点选后自动前进、返回修改、重新测试和 PNG 分享卡下载。答案仅保留在页面内存中，不上传、不收集个人信息。

## 本地运行

需要 Node.js 22 或更新版本。

```bash
npm ci --cache /workspace/.npm-cache
npm run dev
```

开发服务默认使用 5173 端口。云环境中的对外访问方式取决于平台，不代表已经部署到公网。

## 构建

```bash
npm run build
npm run preview
```

构建产物在 `dist/`，可以部署到支持静态网站的托管平台。本项目不需要后端、数据库或 API 密钥。尚未接入小红书小游戏平台。

## 主要文件

- `src/main.js`：题目、结果、多个倾向累积的趣味计分、页面交互与分享卡绘制。
- `src/style.css`：响应式界面、田园配色与减少动态效果支持。
- `public/village.png`：首页和分享卡使用的小镇插画。
- `public/scenes/`：10 道题各自独立的 WebP 场景插画；题目与图片的对应关系、描述与章节标题在 `src/main.js` 的 `questionScenes` 中维护。答题时会提前加载下一题图片。

本测试是娱乐性的自我探索，不是经过心理学验证的量表，不用于诊断。

## 字体与界面

界面使用深色梦幻背景、浅粉选项和随网站分发的霞鹜文楷字体，不依赖外部字体服务。选项点击后保留 380ms 选中反馈再前进，期间防止重复点击；返回与首页操作会取消待执行的跳转。

`public/fonts/twilight-wenkai.woff2` 是按当前文案裁剪的字体，字体许可证在同目录的 `OFL.txt`。更改文案后，可在装有 `fonttools[woff]` 的 Python 环境中执行 `python3 scripts/subset-font.py` 更新字体；原始字体由开发依赖 `@fontsource/lxgw-wenkai` 提供。字体产物已提交，日常部署只需要 Node.js，不需要 Python。

## 已验证功能

生产构建通过。使用 Chromium 在 320×568、360×640、375×667、390×740、390×844、430×932 与桌面 1440×1000 尺寸检查全部 10 题；手机题目和四个选项均可一屏显示。验证点选自动跳题、重复点击防护、返回保留与修改答案、返回和首页取消跳转、结果生成、PNG 下载、重新测试与无 JavaScript 运行错误。文字放大或极小横屏允许正常滚动，以保留可读性。手机系统的保存图片体验仍需在真实设备上确认。
