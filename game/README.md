# 归宅

无依赖的网页恐怖小游戏。当前正式流程：开始画面 → 两幕背景说明 → 第一晚回到老宅 → 开灯、上二楼 → 点击最右自己的房门进入卧室 → 调查窗台、散落书本 → 点击床选择休息 → 奶奶来电。第一晚平安无事，其他房间和次日剧情暂未制作。

第一晚手机无短信、无未接来电，也没有消息红点；菜园暂不开放，门口画面除大门外没有场景点击反馈。进入客厅后，除灯、楼梯以及必要的转身导航外，点击电视、房门、手电筒或工具栏均提示“今天赶路累了，夜深了，先休息。”到二楼后点击自己的房门进入卧室；睡前接到奶奶来电。没有危险入侵或停电，不自动进入第二天。

## 本地运行

在仓库根目录执行 `python3 -m http.server 8000 --directory game`，用浏览器访问本地服务。也可直接打开 game/index.html，无需构建或安装依赖。

## 本地存档

进入游戏后自动保存房间、灯光、工具箱、线索、声音设置及电话对白进度。再次打开同一地址时，在开始界面选择“继续游戏”；“重新开始”需确认，并清除当前进度和个人记录。原有第二天存档会自动迁移。

存档保存在当前浏览器的本地存储中，不跨设备或浏览器同步；清理网站数据、使用无痕模式或更换游戏文件路径/网站地址可能导致原存档不可用。画廊独立预览不覆盖正式进度。夜间短过场恢复到来电或第二天，停电测试恢复到断电前的安全进度，不恢复倒计时。

回归测试：安装 Playwright 和 Chrome 后运行 `node tests/save.cjs`（仓库根目录），可用 `CHROME_PATH` 指定浏览器路径。

## 第二天调查与拾取

第二天客厅灯默认开启，之后保留玩家自己的开关选择。爷爷奶奶房使用独立全景，可点击衣柜、地上纸条和缝纫机抽屉；纸条原文为“有些工具在二楼杂物间，钥匙就摆在抽屉里。”抽屉采用全屏调查近景，确认拾取后切换到同机位空抽屉，取消保留钥匙；返回、刷新和放回原处均保留对应状态。钥匙成功解锁二楼杂物间后消耗，腾出一格且不再出现在抽屉；旧存档中已开门的钥匙也会自动移除。阁楼第二天仍不可进入。手电筒拾取后，客厅亮灯、灭灯画面均切换到无手电筒版本，放回时恢复。

钥匙和手电筒都需要确认后才能收进工具箱；取消不改变物品，最多携带4件，可从工具箱将物品放回原处。拾取状态、杂物间门锁均随进度保存；兼容此前仅记录手电筒的存档。测试运行 `node tests/exploration.cjs`。

## Netlify 发布

1. 登录 Netlify，选择 Add new project → Import an existing project → GitHub。
2. 授权访问并选择 kunkun2222/codex，部署分支选择 main。
3. Base directory 留空，Build command 留空，Publish directory 填 game。根目录 netlify.toml 已声明发布目录。
4. 点击 Deploy，完成后打开 Netlify 提供的网站地址。

也可将 game 文件夹拖到 Netlify Drop 发布。之后向 main 推送更改，可触发已连接站点的自动部署。

game.js 保留了之前的完整剧情草稿，当前网页只加载 demo.js。

## 图片画廊

打开 `game/gallery.html` 可查看十张场景作品，支持放大与下载。GitHub 中也可打开根目录 `GALLERY.md`。大门口分别采用 `entrance-v3-on.png` 与 `entrance-v3-off.png`：灯光状态直接决定显示哪张，视角切换没有从亮到暗的滤镜动画。两张图均已去掉门左侧墙面开关。

## 菜园线索预览

菜园是独立场景 `assets/garden-v1.png`，不是外景放大。画廊中的“单独预览线索互动”或 `index.html?preview=garden` 可进入美术测试：点击左侧断梗、右侧脚印分别获得线索，备忘录会记录。这个入口仅用于检查美术与交互，正常第一晚不会解锁菜园，也没有新增次日剧情。

## 客厅开关与电视

最左侧墙面开关控制客厅灯，楼梯口开关独立控制楼梯灯。状态在切换视角时保留，刷新页面重置。电视四模式逻辑暂时保留供后续剧情使用，但第一晚点击只提醒休息，不开机。节目为静态示意画面，无音视频。

`demo.js` 的 `firstNight` 和 `gardenUnlocked` 管理当前流程；`restReminder` 统一疲劳提示；`restForNight` 是第一晚上楼休息节点。尚未制作其他房间。

## 二楼楼梯间

`upstairs-v2-on.png` / `upstairs-v2-off.png` 为同机位亮灯、灭灯图。左侧小门为杂物间，旁边陡木梯通无灯阁楼，中间为父母卧房，右侧为女主卧房，所有房门关闭。右墙开关与一楼楼梯灯共用 `stairLight` 状态，中间墙开关控制独立 `hallLight`。右下角返回一楼；各状态跨楼层保留。

第一晚只有自己的房门推进休息节点；其余门、阁楼木梯及空白区域都提示先休息，开关与返回按钮仍正常操作。卧房内部已制作，窗户逃生和其他卧房未开放。

二楼第二版进一步缩小杂物间门，并加入菜篓、旧桶、竹筐纸箱、木凳、草帽、布袋和朴素墙饰，亮灯与灭灯图同步。

## 卧室与睡前来电

`bedroom.js` 集中管理卧室两条线索、床的睡觉/等会选择、淡黑和奶奶来电。`familyDialogue` 可编辑人物名字与对白。点击床→睡觉后先渐黑，再来电，必须接听后逐句推进。通话后保留第一晚、不解锁菜园；返回卧室再睡不会重复来电。

铃声由浏览器 Web Audio 合成，不依赖网络或付费服务。默认关闭，可在开始画面或底部工具栏开启；来电时也能开关。铃声最多12秒，接听、静音、切走页面或窗口失焦会停止。人物目前只有文字对白，无配音。可在画廊独立预览卧室。
